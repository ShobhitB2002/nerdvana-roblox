# NERDVANA

A Roblox MMORPG survival grinder with Albion-style progression — kill mobs, gather resources, craft gear, climb the tier ladder.

Built with Rojo for a proper local dev workflow (VS Code + Luau, no Roblox Studio lock-in).

## Concept

- Zone-based mob spawning with scaling difficulty
- Resource gathering and crafting system
- Gear tier progression (inspired by Albion Online)
- Persistent player data

## Tech

Luau · Rojo 7.6.1 · Roblox Studio

## Dev Setup

Requires Rojo 7.6.1+

```
rojo serve
```

Then connect from Roblox Studio via the Rojo plugin.
