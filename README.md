# NERDVANA

Roblox MMORPG survival grinder — Albion-style gear progression, Rust-style material clarity.

## Play / Test

1. Open `Nerdvana.rbxlx` in Roblox Studio.
2. Press **Play** (F5). That's it — the island, NPCs, mobs and UI are all generated by scripts.

## Controls

| Key | Action |
| --- | --- |
| E | Gather / use station / portal |
| F | Talk to NPC |
| Left click (or ⚔ on mobile) | Attack |
| I / Bag | Inventory |
| M | Mastery panel |
| R / Rebirth | Rebirth window |
| C / Pets | Companions & eggs |
| N / Index | Collection index |
| G / Gifts | Daily rewards, playtime chests, codes |
| B / Shop | Robux + diamond shop |
| P | Admin panel (owner only) |
| Shift | Sprint |

## Core loops

1. **Tutorial:** gather → refine → craft → fight → Bandit Captain → Ancient Gorehorn → Corrupted Portal (NG+ island).
2. **Rebirth:** beat the Beast Boss → rebirth at the shrine → permanent +25% gold/XP per rebirth + tokens for the perk shop; world hits harder each rebirth.
3. **Collect:** hatch companions from 4 egg tiers (secret 1-in-2000 VOID LORD), fuse dupes, fill the index for diamond milestones, climb village leaderboards.
4. **Return:** daily login streak, rotating daily quest, playtime chests, promo codes.

## Development

```bash
rojo build -o Nerdvana.rbxlx        # build place file
rojo serve                           # live-sync to Studio
rojo sourcemap default.project.json -o sourcemap.json
luau-lsp analyze --definitions=globalTypes.d.luau --sourcemap=sourcemap.json src   # typecheck
```

Tools are managed by [Rokit](https://github.com/rojo-rbx/rokit) (`rokit install`).

## Architecture

- `src/ReplicatedStorage/Modules` — data: ItemDB, RecipeDB, MobDB, QuestDB, MasteryDB, RarityRoller, WeightSystem, Shared (categorized-inventory helpers)
- `src/server` — DataServer (saves), QuestServer (server-authoritative quests), IslandGenerator (deterministic map), MobAI, Gathering/Refinement/Crafting/Combat/Death/Portal/NPCDialog servers
- `src/client` — GuiSetup builds all UI; one client script per system
